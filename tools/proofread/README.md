# 科判校对原型（kpcheck）

纯规则比对，不用 AI。读科判 Word 原稿（表格），可选再读讲记 Word，列出疑点。

```
pip install python-docx pdfplumber opencc-python-reimplemented
python tools/proofread/kpcheck.py 科判.docx [讲记.docx 或 讲记.pdf] [--tree]
python tools/proofread/fjcheck.py 简体科判.docx 繁体科判.docx
```

检查项目：
- 科判表自身：「分N」与实际子科判数、同级序号连续、同级编号样式、全角半角混用、（表X）引用、总表与分表写法一致
- 对照讲记：讲记标题（汉仪粗宋简字体）与科判一一对应、讲记「分N：……」列表、标题标点与括号
- 经文：科判表正文栏 vs 讲记随文经文 vs 讲记卷首经文，逐字三方比对（异体字单独标出）

- 颂词每句字数一致（提示漏字、多字）
- 表格标题「表X：（N表）」格式、表号连续、张数相符

- 表格标题与表内容相符（如标题写第二品、表里却是第三品）
- 讲记文件不全时，整段报一次，不逐条报
- 本书统一的写法（如通篇「1.」「甲一」不加顿号、讲记分科一律用「一、」）当作体例，不逐条报
- fjcheck：繁体版转成简体后与简体版逐格比对，另列简体版里留下的繁体字

已用五套样本调过：普贤行愿品、佛为阿难说人处胎会、君规教言论释、普贤赞、无常悲歌。
第二轮又用 14 套调过（愿海舟、普贤行愿初机导引上、萨迦格言、水木格言、破妄念佛说、弥陀经初机导引、入大乘愿文、唐译阿弥陀经、归依六支论、他空承许狮吼论、金刚萨埵法门、劝修易行道、地藏赞、格言宝藏论释），以及 3 套繁简对照。
支持的编号写法：甲一、／甲一（古式无顿号）／甲初、甲、乙、；第N品/章/节/目/篇/课、第一、；一、／一者、／「一 名称」空格式；（一）；1、1.／１、；（1）；1）；①；上/下篇；「名称第N」；「21、」层层相接编号。
讲记标题字体自动识别；讲记里的经文按内容识别，不靠字体；讲记可以是 Word 或 PDF（PDF 页边文字可能混入，结果要人看）。
